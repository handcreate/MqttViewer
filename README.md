# MqttViewer



## 项目介绍

一个具备聊天式界面、智能订阅管理和消息可视化分析能力的 MQTT 调试工具：

* 多主机管理：支持多个 MQTT 连接配置
* 主题订阅管理：支持通配符订阅、动态增删、精准匹配来源
* 聊天式交互界面：消息以对话流形式展示，更直观
* 消息展示优化：按主题分颜色区分
* 新消息提醒：托盘闪烁/提示，避免遗漏消息
* 消息统计分析：按主题/分类统计接收数量
* 历史记录持久化：自动保存至系统目录，支持回溯查看
